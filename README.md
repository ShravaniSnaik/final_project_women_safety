# flutter_application_2

Smart Women’s Safety Application
🔰 Introduction
In recent years, growing concerns over women's safety have highlighted the urgent need for innovative solutions that can provide immediate assistance during emergencies. This project addresses that need through the development of a smart safety application that enhances personal security via real-time alerts, location tracking, and AI-assisted emotional support. With a user-friendly interface and powerful backend features, the app empowers women to take control of their safety while ensuring their guardians are informed and connected.

🌟 Key Features
🚨 Shake-to-Alert Mechanism
By simply shaking the phone, users can instantly send an emergency alert to their registered contacts (parents, friends, or guardians). This discreet activation method allows users to seek help without unlocking or operating the phone manually.

📍 Live Location Sharing via SMS
Once an alert is triggered, the app automatically shares the user’s real-time location with emergency contacts via SMS using the telephony package. This enables quick tracking and timely assistance.

👮 Emergency Call to Nearby Police Stations
The app includes a feature to identify and contact nearby police stations, ensuring that law enforcement can be informed without delay.

🗺️ Unsafe Area Mapping
Using historical data and user reviews, the app marks unsafe areas in red on a digital map. This helps users plan safer routes and avoid high-risk zones.

📞 Emergency Contact Directory
A dedicated section provides a list of verified emergency numbers, including women’s helplines, local police stations, and ambulance services.

📚 Safety Articles and Tips
Users can access informative articles on women’s safety, self-defense techniques, and precautionary advice. Motivational quotes are also featured to offer emotional support and encouragement.

🤖 AI-Powered Auto-Counselor Chat
Developed for the Perplexity Hackathon, this feature integrates the Perplexity sonar-pro model API to offer an empathetic AI counselor. Users can type their thoughts or distress messages, and the counselor responds like a trusted friend—calm, concise, and emotionally supportive. If the system detects emergency phrases (like "I want to die" or "can’t take it"), it automatically:

Fetches the user's GPS location.

Constructs a SOS message.

Sends it to emergency contacts via SMS, alerting them in real-time.

This bridges the gap between emotional support and physical safety intervention.

🧠 Chatbot for Communication
A simple chatbot facilitates real-time communication between the user and their emergency contacts. It keeps the guardians updated on the user’s status during alerts.

🗣️ Location Safety Review System
Users can rate and review the safety of places they’ve visited. These reviews build a community-driven safety map, helping others make informed decisions when visiting new areas.

👤 User Roles & Accessibility
Girl (User): Can trigger alerts, share locations, chat with guardians, and provide safety feedback on places.

Parent/Friend (Guardian): Receives alerts, tracks live location, and communicates with the user during emergencies.

Admin: Manages user authentication, monitors video recordings (if any), and maintains the backend for reliability and security.
